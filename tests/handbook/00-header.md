# WordPress Plugin Developer Handbook — Offline Reference

A consolidated, offline copy of the [WordPress Plugin Developer Handbook](https://developer.wordpress.org/plugins/), compiled for use as a reference when building WordPress plugins. Content is sourced from developer.wordpress.org; where the handbook has reorganized URLs, the current equivalent page was used and noted inline.

> Compiled 2026 for general WordPress plugin development reference. Function signatures and guidelines reflect the handbook as published at compile time — always cross-check the live handbook for the latest API changes and directory guidelines.

## Table of Contents

1. **Introduction & Plugin Basics** — what a plugin is, header requirements, activation/deactivation hooks, uninstall methods, best practices, plugin & content directories
2. **Plugin Security** — checking user capabilities, data validation, sanitizing input, escaping output, nonces
3. **Hooks & Administration Menus** — actions, filters, custom hooks, advanced topics; top-level and sub-menus
4. **Settings & Metadata** — Settings API, Options API, custom settings pages; post metadata and meta boxes
5. **Shortcodes, Custom Post Types & Taxonomies** — registering and working with each
6. **Users & HTTP API** — working with users, roles & capabilities, user metadata; `wp_remote_*` requests
7. **JavaScript / Ajax & Cron** — enqueuing scripts/styles, admin-ajax, localization, Heartbeat; WP-Cron scheduling
8. **Internationalization & Privacy** — i18n functions, `translators:` comments, localization; privacy policy text, data exporters/erasers
9. **Publishing: Plugin Directory & Developer Tools** — planning, SVN, readme.txt, plugin assets, the full plugin guidelines, developer tools
