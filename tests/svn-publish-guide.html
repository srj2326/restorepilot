The shape of the repository

Three folders, each with a different job. This trips up almost everyone the first time — worth thirty seconds before you touch a terminal.

trunk/
you'll edit this
The live, current code. No wrapper folder inside it — unlike the zip you're used to, the plugin's own files sit directly in trunk/.
tags/0.5.0/
you'll edit this
A frozen copy of one exact release. What a user gets when they install version 0.5.0 specifically. Same contents as trunk today.
assets/
optional, later
Icon, banner, screenshots for the listing page itself. Never installed on anyone's site. Covered at the end of this guide.
1

Get your SVN password

It is not your WordPress.org login password — a separate one, used only for SVN. Open your profile and set or copy it:

profiles.wordpress.org → Account & Security → SVN password

!

Your username is case-sensitive: exactly srjdev, as registered.

2

Check out the repository

Open Terminal and pull down your (currently empty) plugin repo:

Terminal
mkdir -p ~/Desktop/restorepilot-svn
svn checkout https://plugins.svn.wordpress.org/restorepilot-backup-migration ~/Desktop/restorepilot-svn

It may ask you to accept a certificate the first time — type p to accept permanently. You should see trunk/ and tags/ already there, empty. That matches the email: nothing's been uploaded yet.

3

Copy in today's release

This pulls in the files already staged and verified on this Mac — the fixed 0.5.0 build, not the older reviewed one:

Terminal
SVN_STAGE="/private/tmp/claude-501/-Users-surajitroy-Local-Sites-morecalculators-dev-app-public-wp-content-plugins-restorepilot-backup-migration/7f9a6ea2-0e0d-47e3-9219-e411bdf20a00/scratchpad/svn-stage"

mkdir -p ~/Desktop/restorepilot-svn/trunk ~/Desktop/restorepilot-svn/tags/0.5.0
cp -R "$SVN_STAGE/trunk/." ~/Desktop/restorepilot-svn/trunk/
cp -R "$SVN_STAGE/tags/0.5.0/." ~/Desktop/restorepilot-svn/tags/0.5.0/
4

Tell SVN about the new files

add only marks files for the next commit — nothing leaves your Mac yet. Then look at exactly what's about to ship:

Terminal
cd ~/Desktop/restorepilot-svn
svn add --force trunk tags
svn status

Every line should start with A (added). If anything unexpected shows up, stop here and ask before continuing.

5

Commit — this is the moment it goes live

One command, and it's public:

Terminal
svn commit -m "Initial release 0.5.0" --username srjdev

It will prompt for the SVN password from step 1. Typing is invisible in the terminal — that's normal, keep typing and press return.

→

After this finishes, anyone can install your plugin. Nothing before this step is public — this is the one to pause on if you want a last look.

6

Check it went live

Visit your listing — usually ready within a few minutes:

wordpress.org/plugins/restorepilot-backup-migration

✓

WordPress.org's own email said search results and your profile can take up to 72 hours to catch up — that's normal and separate from the plugin actually being installable.
